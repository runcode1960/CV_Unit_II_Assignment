# Computer Vision — Unit II Assignment

This repository contains Python programs and output images for **Computer Vision Unit II** image-processing exercises.

## Topics covered

| No. | Exercise |
| --- | --- |
| 01 | Grayscale conversion |
| 02 | Brightness adjustment |
| 03 | Contrast stretching |
| 04 | Histogram |
| 05 | Histogram equalization |
| 06 | Mean filter |
| 07 | Gaussian filter |
| 08 | Median filter |
| 09 | Filter comparison |
| 10 | Sharpening |
| 11 | Smoothing vs. sharpening |
| 12 | Discrete Fourier Transform (DFT) |
| 13 | Magnitude spectrum |
| 14 | Frequency-domain low-pass filter |
| 15 | Frequency-domain high-pass filter |

## Project structure

Each numbered folder contains:

- `program.py` — the Python implementation
- Input image(s) used by the program
- Output image(s) produced after processing

## Requirements

- Python 3
- OpenCV
- NumPy

Install the required libraries with:

```bash
pip install opencv-python numpy
```

## Running a program

Open a terminal in this project folder and run the required program. For example:

```bash
python 01_Grayscale/program.py
```

The processed result is saved as an output image in the corresponding exercise folder.
